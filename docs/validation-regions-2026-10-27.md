# 1.3.0 多地区恢复验收

## 实现规则

- 根据可直接选择的代理叶子节点识别地区，展示地区数、节点数与未识别数量。
- 地区设置支持复选框、上移／下移、“应用并保存”和取消；首次默认日本，重启恢复已保存的勾选与顺序。
- 当前地区已勾选时先尝试当前地区，失败后从排序首位继续，跳过本轮已经尝试的地区。当前地区未勾选或未知时直接从排序首位开始。
- 每地区内部按本轮延迟排序，实际代理验证失败后尝试同地区下一节点，再进入下一地区；全部失败后等待 10 秒开始新一轮。
- 连续两轮检查失败才恢复，代理健康时保持当前选择；应用设置会使旧测速失效，保存失败保留旧策略。

## 真实界面与隔离恢复

两端均使用四地区、六节点的隔离 Clash 夹具，初始节点在日本。通过真实窗口完成：

1. 勾选香港、新加坡并将香港上移，取消后仍保持仅日本，未写入设置。
2. 再次编辑并保存“香港 → 日本 → 新加坡”，确认文件和界面顺序一致。
3. 启动监控，连续两轮故障后首先测试日本；主、备用地址均无有效结果，再测试香港。
4. 只选择香港最快的 30 ms 节点并确认代理恢复。没有重复进入日本，没有测试新加坡或未勾选的美国。
5. 重启应用后，香港、日本、新加坡仍勾选，排序保持不变，美国仍未勾选。

macOS 验收使用实际 Avalonia 窗口和渲染截图；Windows 在已登录桌面会话 1 中通过 UI Automation 操作控件。已检查勾选、排序、中文布局、禁用的首尾排序按钮和测速恢复状态截图。
