# Herdr Auto Continue

简体中文 | [English](README.en.md)

写方案、整理需求，或者让 AI 跑一个比较长的任务时，最烦的就是它因为“服务繁忙”或临时网络问题停下来，还得你回来点一次“继续”。

Herdr Auto Continue 就是帮你照看这一步的小工具。它会留意本机 Herdr 里的任务，遇到能重试的这类错误，等至少 10 秒，确认任务仍停在原处后，自动发送“继续”。如果是代理出了问题，还能从你选好的订阅和地区里找可用节点，网络恢复后再续接任务。

目前支持自动续接 **Codex 和 OMP**。任务正常完成、你主动停止、需要你确认，或遇到登录、额度、限流等问题时，会留给你处理。

## 下载与准备

到 [最新版本下载页](https://github.com/lzl51230/HerdrContinue/releases/latest) 选择对应安装包：

| 你的电脑 | 下载哪个 | 怎么打开 |
| --- | --- | --- |
| macOS 14 或更新版本，Apple Silicon（M 系列芯片） | `HerdrAutoContinue-osx-arm64.zip` | 解压后，把 `Herdr Auto Continue.app` 放进“应用程序” |
| Windows 10 22H2 / Windows 11，64 位 | `HerdrAutoContinue-win-x64.zip` | 解压到固定文件夹，运行 `HerdrAutoContinue.exe` |

安装包已经带好了运行所需的组件，不用再装 .NET。Windows 11 和 M 系列 Mac 已做过实机验证；Windows 10 尚未实机验证。目前 macOS 包未做 Apple 公证，Windows 包未做商业代码签名，系统可能会显示来源提示。

使用前，先确认 **Herdr 已安装，并能正常打开你的 AI 会话**。代理恢复功能使用 **Clash Party**，本地代理端口需要设为 **7890**；想让程序自动切换节点，还要把 Clash Party 切到**全局模式**。

## 第一次使用

1. 打开 Herdr 和 Clash Party，确认平时使用的网络能连通。
2. 打开 Herdr Auto Continue，点击代理卡片里的“**切换设置**”。
3. 在“**订阅源**”里勾选允许使用的订阅，在“**地区与排序**”里勾选地区，用 ↑ / ↓ 调整顺序，最后点“**应用并保存**”。
4. 打开应用后，续接服务会自动运行。它会关注这台电脑上所有 Herdr 会话，并显示任务状态、倒计时和续接次数。

首次使用默认选择**当前订阅和日本地区**，你可以按自己的情况修改。升级会保留已有的地区选择与排序，新增的订阅和地区需要你手动勾选。

## 代理掉线后，它会怎么选节点？

先在当前地区找候补，前提是这个地区已经勾选；没有可用节点时，再按你排好的地区顺序往下找。比如你选了日本、香港、新加坡，当前用的是日本节点，就会先尝试日本，再尝试香港、新加坡。

同一地区里，**所有已选订阅的节点会一起测速**，优先用最快且能实际连通的节点。这一个不行，就试同地区的下一个；整个地区都不行，再换地区。不同订阅里即使有同名节点，也会分开识别，界面会显示节点来自哪个订阅。

有两条规则可以记一下：

- 同一地址连续两次测速都超过 **800 ms**，就按节点超时处理。这条规则也用于当前节点的连通性检查。
- **当前代理正常时，会保持现有节点**，不会为了追求更快而一直切换。如果没有勾选任何订阅或地区，就只检查连通性，不自动换节点。

程序会把所选订阅的节点合到一起使用，原订阅文件会保留。想只使用 Clash Party 当前选用的那份订阅，点击“恢复原配置”即可，地区顺序会保留。停止服务或退出应用，也会保留当前的代理配置和节点。

## 日常怎么用

| 你想做什么 | 怎么操作 |
| --- | --- |
| 暂时收起窗口，让它继续工作 | 直接关闭窗口。它会留在菜单栏或系统托盘里 |
| 暂停自动续接和代理监控 | 点“停止服务”，当前代理节点会保留 |
| 完全关掉程序 | 点窗口底部的“退出应用”，或菜单栏／托盘菜单里的“退出” |
| 登录电脑后自动运行 | 打开“设置”，勾选“登录后自动启动并运行续接服务”，再保存 |
| 换个顺眼的配色 | 在“设置 → 颜色主题”里选择，支持跟随系统和六套 VS Code 风格主题 |

手动打开一个新进程就会自动运行续接服务，无需开启登录自启动。开启登录自启动后，登录电脑会启动应用和续接服务。设置中勾选“静默启动”后，手动或登录启动新进程都不显示主界面；未勾选时都会显示。静默启动默认关闭，旧配置升级后也默认关闭。如果应用已经在后台运行，再次打开只会显示窗口，不会重新启动你刚刚手动停止的服务。

主题选中后就能预览，点“应用并保存”才会保留；取消会恢复原来的配色。启动／停止服务也可以用快捷键：Mac 按 **⌘Enter**，Windows 按 **Ctrl+Enter**。

## 常见问题

**为什么打开后没有自动工作？**

手动打开应用的新进程后，服务会自动运行；如果本次已手动停止，请点“启动服务”。想登录电脑后也自动运行，可以在设置中开启登录自启动。如果还没打开 Herdr 或 Clash Party，程序会等待并重试，主窗口里会显示当前状态。

**为什么某个报错没有自动点“继续”？**

它只处理能识别的临时容量和网络错误。正常结束、人工停止、等待确认、登录或额度等问题不会自动处理；输入框里有草稿时也不会代你发送。可以先看任务旁边的说明。

**为什么某个订阅选不了，或者没有节点？**

先到 Clash Party 里更新订阅，再回来点“刷新列表”。程序使用 Clash 已下载到本机的节点；有些带自定义处理或缺少所需内容的订阅暂时无法合并，界面会提示原因。订阅的下载和更新仍在 Clash Party 中完成。

**Mac 上自启动提示需要许可，怎么办？**

按提示点“前往设置”，到系统设置的“通用 → 登录项”里允许应用在登录时打开。建议把应用固定放在“应用程序”里，移动或升级后再检查一下自启动状态。

**想确认它刚才做了什么？**

主窗口下方有操作日志，可以看什么时候开始等待、切换了哪个节点，以及是否续接成功。需要排查时，点“打开日志文件”查看；日志不保存完整对话。
